Oversized gold numeral + white statement + cited source — the navy Stat Band unit.

```jsx
<StatBlock value="1 in 5" statement="U.S. adults live with a mental illness each year."
  source="Source: NIMH, 2023" />
```

Every figure must be sourced and verifiable — cite SAMHSA / NIMH / NIH in `source`. Never invent numbers.
