One value in the Values Row — icon circle + gold caps title + one-line copy. Use three across, divided by `.sbhg-vrule` gold dividers.

```jsx
<ValueItem icon={<i data-lucide="shield-check" />} title="Integrity">
  We do the right thing.
</ValueItem>
```

Lift the three brand values straight from the badge back: Integrity / Compassion / Excellence.
