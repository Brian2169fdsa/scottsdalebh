1.5px gold-outlined circle holding a line icon — the badge-back value/feature icon. Outline only, never filled.

```jsx
<IconCircle size={76}>
  <i data-lucide="shield-check" style={{ width: 32, height: 32, strokeWidth: 1.5 }}></i>
</IconCircle>
```

Use Lucide (or any line icon) inside, ~40% of the circle, stroke-width 1.5. `onDark` controls gold-300 vs gold-700 icon color.
