The SBHG logo lockup — gold cross badge mark + SCOTTSDALE gold caps over the white letter-spaced subtitle.

```jsx
<BadgeMark markSrc="assets/badge-mark.png" size={56} />
<BadgeMark size={40} showType={false} /> {/* mark only */}
```

Copy `assets/badge-mark.png` into your project and point `markSrc` at it. Subtitle is white by default (for navy); set `onDark={false}` over light backgrounds. All type scales from `size`.
