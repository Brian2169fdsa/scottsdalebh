Section title device — gold eyebrow + uppercase H2 + the signature gold underline rule. Use to open every major section.

```jsx
<SectionHeading eyebrow="Why Scottsdale" align="center">
  A higher standard of care
</SectionHeading>
```

Set `onDark` for white text on navy sections. `align` `left`/`center` also centers the rule. `as` controls the tag (`h1`–`h3`).
