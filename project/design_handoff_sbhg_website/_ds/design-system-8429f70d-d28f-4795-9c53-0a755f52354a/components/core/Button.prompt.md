Gold-gradient call to action with surface-aware outline variants — use for every CTA; labels are verbs ("Verify Insurance," "Call Now").

```jsx
<Button variant="primary" size="lg">Verify Insurance</Button>
<Button variant="secondary-dark">Our Programs</Button>
```

Variants: `primary` (gold gradient, navy text), `secondary-dark` (gold outline on navy → fills gold on hover), `secondary-light` (navy outline on light), `ghost` (gold text only). Sizes: `sm` / `md` / `lg`. Pass `href` to render an anchor, `iconLeft` / `iconRight` for icons.
